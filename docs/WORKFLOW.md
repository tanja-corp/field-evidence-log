# 回し方

入れる → 整える → 見せる → 返す → 直す、を繰り返す。

1. **入れる**：フォーム、Claudeへの会話、JSONの直接編集のどれでもよい。
2. **整える**：Claudeが状況・したこと・分かったこと・学びにそろえ、足りない材料を挙げる。
3. **見せる**：GitHub Pagesの画面で、構成・記録・学び・面接素材として確認する。
4. **返す**：スライドごと、問いごとに OK／直す／保留 とコメントを返す。
5. **直す**：Claudeが返事を読み、PPTXと記録を直し、`changelog.json` に残す。

## 確度を上げる手順

⚠️ → ✅ は、次の3つがそろい、本人が確認したときだけ。

- 数字と出典（URLか資料名）
- 自分の役割（設計、作業、観察のどれか）
- 言ってよい範囲（公開してよいか）

そろったら `entries.json` の `fact_tag` を ✅、`status` を `confirmed` に直す。
就活用の台帳へは `python scripts/export_facts.py` の出力を貼る。
